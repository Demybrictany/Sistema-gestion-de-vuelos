
# Procedimiento de gestión de vuelos retrasados

## 1. Objetivo
Describir el proceso de registro, seguimiento y comunicación de vuelos retrasados mediante el Sistema de Gestión de Vuelos.

## 2. Identificación del retraso
El personal autorizado consulta la información del vuelo, incluyendo su código, horario, estado y puerta asignada.

## 3. Actualización del estado
Cuando se confirma un retraso, el personal autorizado registra el estado RETRASADO en el sistema y verifica que la información del vuelo esté actualizada.

## 4. Comunicación a pasajeros
El personal utiliza el módulo de notificaciones para informar sobre cambios de horario, puerta de embarque y estado del vuelo.

## 5. Seguimiento
El personal consulta periódicamente el estado del vuelo y actualiza la información cuando se presentan cambios.

## 6. Consulta mediante el agente de IA
El agente de inteligencia artificial puede recuperar este procedimiento desde la documentación RAG para responder preguntas relacionadas con la gestión de vuelos retrasados.

## 7. Consideraciones
La información operativa debe verificarse en la base de datos antes de comunicarla. El agente de IA no debe inventar horarios, estados ni asignaciones de puertas.
